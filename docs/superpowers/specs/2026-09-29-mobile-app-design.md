# 온달력 모바일 앱 설계

## 목표

웹 버전의 핵심 캘린더 경험을 iOS와 Android 앱으로 제공한다. 초기 출시에는 결제 UI를 포함하지 않지만, 이후 웹·iOS·Android 결제를 계정 기준 프리미엄 권한으로 통합할 수 있도록 경계를 미리 둔다.

## 범위

- Google 로그인 및 Supabase 세션
- Google·iCloud·회사 일정 연결
- 월간·주간·일간 일정 조회
- 일정 등록·수정·삭제 및 음력 반복
- 연결·동기화 오류 안내
- 전체 모바일 앱과 함께 제공되는 iOS WidgetKit·Android App Widget
- 무료 사용자 광고 표시 및 프리미엄 구매 시 광고 제거

프리미엄 결제와 위젯의 최종 표시 내용은 초기 앱 본체 안정화 이후 별도 작업으로 확정한다.

## 기술 구조

- 앱: React Native 기반 공통 화면, iOS·Android 네이티브 위젯 확장
- 인증: 기존 Supabase Auth와 동일 계정 사용
- 데이터: 기존 온달력 API와 Supabase 연결정보 재사용
- 권한: 계정별 `free`/`premium` entitlement를 조회하는 공통 API 경계 마련
- 광고: 무료 entitlement에서만 광고 슬롯을 활성화하고, `premium`이면 모든 앱 광고 슬롯을 비활성화
- 위젯: 전체 앱을 보조하는 필수 홈 화면 기능으로, 앱과 공유 가능한 최소 일정 요약 데이터를 저장하고 플랫폼별 위젯이 이를 읽도록 구성

## 데이터 흐름

앱 로그인 → Supabase 세션 확보 → 기존 캘린더 API 호출 → 일정 표시·변경 → 성공 시 위젯 공유 저장소 갱신. 결제 도입 시 결제 플랫폼 검증 결과를 서버에서 entitlement로 기록하고, 앱과 웹은 동일한 권한 API를 조회한다.

무료 사용자는 일정 내용과 분리된 광고 슬롯을 볼 수 있다. 프리미엄 entitlement가 활성화되면 광고 SDK 호출과 광고 슬롯을 모두 비활성화한다. 광고 SDK에는 일정 제목·내용·캘린더 인증정보를 전달하지 않는다.

## 오류 처리

연결 만료, 권한 부족, 일시적 네트워크 오류를 구분해 웹과 동일한 안내를 제공한다. 일정 제목·내용·토큰은 분석 로그에 저장하지 않는다.

## 검증 기준

- iOS와 Android에서 동일 계정으로 로그인 가능
- 세 플랫폼에서 동일 일정 목록과 변경 결과 확인
- 로그아웃·재로그인 후 연결정보 유지
- 위젯 확장 구조가 각 플랫폼 빌드에서 로드됨
- 초기 버전에는 결제 없이 모든 핵심 기능 사용 가능
- 무료 계정에서 광고가 표시되고, 프리미엄 entitlement에서는 광고가 표시되지 않음
